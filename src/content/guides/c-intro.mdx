## Before the session

- Skim all five module readings yourself; you do not need to master the demos.
- If you run a classroom, open its dashboard and check each student's progress
  column for this module. Note who has not reached
  [the AI Control paper](/tracks/control/introduction/ai-control-paper) — pair
  them with someone further along during the exercise block.
- Check the submissions column for completed written responses; pick one or two
  anonymized excerpts you can read out as discussion starters (ask permission).
- Have the [Control scenarios](/exercises/control-scenarios) exercise open on a
  screen you can share.

## Agenda

Times are a running clock for a 60-minute session; shift every later block if
one runs over, and cut from the debate block first — never from the wrap-up.

### Warm-up: what is control? (0:00–0:10)

State the session goal, then have two or three participants state the core bet
of
[the case for controlling powerful AIs](/tracks/control/introduction/the-case-for-controlling-powerful-ais)
in one sentence each, without looking. Write the phrasings on the whiteboard
and let the group edit them into one agreed sentence; leave it up all session.

Prompts:

- "What would have to be true about a model for control, as the reading
  defines it, to stop being enough?"
- "Where does control end and alignment begin — one sentence each?"
- If the room stalls: "Does control assume the model is misaligned, or does it
  only refuse to assume it isn't? Which did the reading actually say?"

### The control game, together (0:10–0:30)

Walk the setup of
[the AI Control paper](/tracks/control/introduction/ai-control-paper): who the
red team is, who the blue team is, what winning means. Then run
[Control scenarios](/exercises/control-scenarios) on the shared screen — per
scenario: read aloud, hand-count vote, one majority voice and one minority
voice defend, then reveal. Save the last few minutes for the assumptions
discussion (prompts below).

Prompts:

- "Which assumption of the game felt least realistic to you, and what would
  change if you dropped it?"
- "What real-world quantity is this game trying to estimate?"
- "If the red team's budget doubled, which scenario's answer flips first?"
- If a vote is unanimous: before revealing, make the room construct the
  strongest case for the answer nobody picked.

### Catching and consequences (0:30–0:40)

In pairs, answer: "According to
[Catching AIs red-handed](/tracks/control/introduction/catching-ais-red-handed),
what changes after the first catch?" Then compare answers across pairs; if the
group wants a structured recap, run
[why catching counts](/exercises/why-catching-counts) on the shared screen.

Prompts:

- "Who needs to be convinced by a catch, and what evidence would actually
  convince them?"
- "What does a false alarm cost, and who pays it?"
- If pairs finish early: "Does the second catch matter as much as the first?
  Why or why not?"

### Threat prioritization debate (0:40–0:55)

Draw the concentrated-versus-diffuse columns from
[Prioritizing threats for AI control](/tracks/control/introduction/prioritizing-threats-for-ai-control)
on the whiteboard. The group places example failures from the readings into a
column; disputed placements get argued, one minute per side. End with a
mind-change round on
[the diffuse-threats reading](/tracks/control/introduction/diffuse-threats-research-sabotage).

Prompts:

- "Which column does this failure go in, and what single feature decides it?"
- "Name a failure that resists both columns. What makes it awkward?"
- "Who changed their mind after the diffuse-threats reading — and on what,
  specifically?"

### Wrap-up (0:55–1:00)

Each participant names one question they still have, in one sentence, no
discussion. Collect these; they are your agenda seeds for the next session and
good prompts for the module's remaining exercises.

Prompt: "What is one question this module raised that the next module had
better answer?"

## After the session

- On the classroom dashboard, check whether participants who attended go on to
  complete the module's remaining readings during the week.
- Read new submissions for the module's written exercises; recurring confusions
  belong on next session's warm-up.
- If several participants asked the same wrap-up question, post it (and where
  the readings address it) in your group's channel rather than waiting a week.
